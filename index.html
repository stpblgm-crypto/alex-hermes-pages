alex-hermes

A personal Google Workspace connection for an owner-operated Hermes assistant. This is not a Google product and is not a public sign-up service.

Purpose

The connection supports owner-requested work with Gmail, Calendar, Drive, Google Docs and Google Sheets. Read operations retrieve only information needed for the requested task. Sending mail, changing events, sharing or deleting files, and editing documents require separate owner authorization; OAuth consent alone does not authorize those actions.

Requested access

The current connection requests seven OAuth scopes: documents, spreadsheets, drive, calendar, gmail.readonly, gmail.modify and gmail.send. They allow reading and, where individually authorized by the owner, modifying the corresponding resources. Contacts access is not requested.

This website

This site contains public documentation only. It does not log in to Google, accept OAuth callbacks or store Google account data. Connection and authorization are handled separately in the owner-controlled installation.

Personal use

The app is intended for its owner. A Google production publishing status does not mean Google has verified or endorsed the app, and does not make the owner's data public. An unverified-app warning may appear.

Documentation contact: repository issues. Never post account data, credentials, authorization URLs or private correspondence in a public issue. For private requests, use the existing private channel with the installation owner.
