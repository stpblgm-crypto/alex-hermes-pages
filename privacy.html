Privacy policy

Effective date: 11 October 2026. Scope: the owner-operated alex-hermes Google Workspace connection and this documentation site.

Google account data and purpose

Depending on an explicitly requested task, the connection can access account identity, email, calendar information, files, documents and spreadsheets under the scopes described on the home page. Data is used for the owner's requested assistant functionality, not as a public data collection service. Write actions require separate authorization.

Credentials and storage

OAuth client credentials and tokens are stored in the private installation, with filesystem access restrictions. They are not included in this website or its public repository. Google account data is not uploaded to GitHub Pages. Task outputs and operational records may be retained in the private installation according to the owner's instructions; this policy does not assert that every operation is transient or that no logs exist.

AI processing and transfers

The connected assistant uses AI services. Any transfer of Google user data to a model provider or another service must be separately authorized by the owner for the requested feature, with the provider's retention and training terms reviewed beforehand. Data must not be used to train or improve generalized or foundation models. This page is not a claim that third-party providers have zero retention. Google user data must not be sold or used for advertising.

alex-hermes use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Implementation and individual operations must respect these requirements.

Revocation, retention and deletion

The owner can revoke the app's access through Google Account connections. Revocation stops further authorized API access but does not by itself delete previously saved task outputs. The owner can request removal of locally stored tokens, retained outputs and related records through their private operator channel. Any authorized third-party copies are subject to that provider's deletion process; no universal immediate-deletion guarantee is made.

Website hosting

This static site has no application analytics scripts, forms, OAuth callback handling or Google-account integration. GitHub provides hosting and may log visitor information, including IP addresses, for security purposes under the GitHub Privacy Statement.

Documentation contact: repository issues. Never post account data, credentials, authorization URLs or private correspondence in a public issue. For private requests, use the existing private channel with the installation owner.
